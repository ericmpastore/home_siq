# HomeSIQ
HomeSIQ is a project app building on my experience in real estate to provide an interface between tenants and real estate investors.

This app will be a pipeline to ensure tenants can communicate comments, concerns, and needs to investors, and allow investors to reply and communicate other important information.

Version 1 of this app will focus on maintenance. Tenants will be able to report necessary repairs and view the status of current repairs with ETA. Investors will be able to view repair requests and respond with the current status.
